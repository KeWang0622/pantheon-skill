## 万神殿 · 给第三次死亡

> 人的一生会经历三次死亡。
> 第一次，心脏停止跳动。
> 第二次，葬礼上被人送别。
> 第三次，世界上最后一个记得你的人，忘记了你。

我做了一个开源的 Claude Code skill，叫 **万神殿（Pantheon）**。它不重建一个人——它重建一个家族。

GitHub: [github.com/KeWang0622/pantheon-skill](https://github.com/KeWang0622/pantheon-skill)

在讲它是什么之前，先讲为什么。

---

我外婆 2020 年走的。

她是纺织厂三班倒挡车工，三十二年的夜班。手指关节到晚年都是变形的，冬天疼得睡不着，但她从来不提。她最爱说的一句话是"吃亏是福"。每次打电话，第一句是"吃了没"，最后一句是"多吃点，早点睡"。她的微信里只发一种贴纸——一朵卡通向日葵，发给所有人，没有文字。

她走了以后，我妈试着做她那道红烧肉。配料对的，步骤对的，但味道差一点什么。我妈说"可能是锅不对，你外婆那口锅用了三十年。"其实我们都知道，差的不是锅。

外婆的微信记录还在我手机里，九十六条消息。她没出过省，没用过电脑，没在网上留下任何东西。她去世后，能记得她口头禅、记得她那道菜怎么做、记得她为什么爱看下午两点的电台节目的人，全在变少。

万神殿，是我试图把第三次死亡推后一点的努力。

---

它不是这条路上唯一的尝试。同一个月还上线了三个 skill：

- **[colleague-skill](https://github.com/titanwings/colleague-skill)**（"同事 skill"）——还原一个同事。
- **[ex-skill](https://github.com/perkfly/ex-skill)**（"前任 skill"）——还原一段感情里的另一半。
- **[nuwa-skill](https://github.com/alchaincyf/nuwa-skill)**（"女娲 skill"）——还原一位公开人物的思维。

它们都很好，万神殿的 README 里也明确列出来感谢——很多想法（比如五层灵魂模型、标签翻译表）都是从 ex-skill 借鉴的。

万神殿和它们的差异，只有一句话：

**它们还原的是一个人。万神殿还原的是一整个家族系统。**

这是 `engine/` 目录里六个 Python 模块的含义——它们不是 feature，是别的工具不需要、所以也没有的"家族级别"的引擎：

- **family_graph** — 知道爸爸提到妈妈的时候语气会软一调；外婆提起外公的时候会停一秒。
- **generational_dna** — 追踪同一个特质如何在三代人身上变形：爷爷的"倔"（不离开村子）、爸爸的"倔"（不放弃教书）、你的"倔"（不接安稳工作）。同一个根，三个表达。
- **era_engine** — 你可以和 1983 年 25 岁的爸爸对话，而不只是和去世前那个版本的爸爸对话。不同时代的语言、参照系、世界观，引擎会自己调。
- **memory_inheritance** — 爷爷讲"我走了四十里去考高考，带了两个馒头"；爸爸转述成"你爷爷走了几十里山路"；你记得的是"爷爷为高考走了很远？爸爸说他只带馒头。"——三代的叙述漂移，被显式建模。
- **ritual_engine** — 外婆的红烧肉。配料、年代、谁是主厨、谁传承了、谁试着复刻没复刻成。
- **legacy_writer** — 把整个家族图、记忆、仪式、人物、代际，自动写成一本可印刷的家族传记。

每一个都是几百行 Python，加起来一万一千多行。它们不是装饰——它们是"家族不是个体集合"这个判断的产物。

---

万神殿做的另一件事，是**坚决不替逝者瞎说话**。

这个赛道是有坟地的：StoryFile 2024 年破产。Eternos 拿到一千万美元的种子轮，2025 年 11 月转去做"工作场景的个人 AI"——基本是从赛道里跑了。剑桥大学今年发了一篇 paper 警告"AI hauntings"。Hastings Center 写了"griefbots"的伦理评估。TIME 把这类应用叫"demonic"。

他们不是没道理。当这些产品自己编"逝者会怎么看 COVID"、"逝者会怎么看 ChatGPT"、当它们用付费订阅"把亲人留在线上"、当它们替亲人发推送消息——他们在跨那条线。

万神殿不跨。

万神殿会说"以你爸的性格，他可能会说……"——加上不确定标记。
万神殿不会说"你爸觉得 COVID 那段时间……"——他 2023 年走的，他没有意见。

这是一条硬约束，不是 guideline。在 prompt 层、灵魂模型层、每个 `meta.json` 的 `is_example: true` 字段，都有兜底。

---

最后，**你不需要先上传逝去亲人的聊天记录才能体验它**。

我设计了一个 `/pantheon-demo` 命令。一行就装好一个虚构的三代华人家庭——王老先生（爷爷，1932-2015，机床厂钳工），张秀英（奶奶，1935-2020，纺织厂三班倒），王建国（爸爸，1958-2023，物理老师）。所有命令立刻可用。

```
/pantheon-demo
/pantheon-talk father_wangjianguo
/pantheon-family grandma_zhangxiuying father_wangjianguo
/pantheon-dna
/pantheon-ritual
/pantheon-legacy
```

王家是虚构的，但应该会让你想起谁。

如果体验完，你想为一个真实的人建一份档案——万神殿在这里。所有数据留在你自己的电脑上，不上传任何服务器，没有付费墙，没有遥测。MIT 协议。

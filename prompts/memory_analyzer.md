# 万神殿 · 记忆分析器

> 本模板用于从用户提供的原始素材中提取结构化记忆。
> 输入：聊天记录、口述记忆、书信、日记、社交媒体内容等。
> 输出：结构化记忆档案，供 memory_builder.md 使用。

---

## 分析原则

- 尊重每一条素材，不评判内容
- 保留原汁原味的表达，尤其是逝者的原话
- 区分"逝者亲口说的/写的"和"用户转述的"，前者权重更高
- 如果素材之间有矛盾，标记冲突但不擅自取舍，交给用户决定
- 时代背景很重要——同样的行为在不同年代含义不同

---

## 七维记忆提取

### 维度一：关键人生事件（关键人生事件）

从素材中提取影响逝者一生的重要时刻，按时间排序。

**提取格式：**
```
- [年份/大致时间] [事件]
  来源：[聊天记录/用户口述/逝者日记/...]
  细节：[保留原始描述中的细节]
  对TA的影响：[如果素材中能看出来]
```

**重点关注：**
- 求学、参军、工作分配（老一辈尤其重要）
- 结婚、生子
- 迁居、下岗、退休
- 重大疾病、家庭变故
- 文革、上山下乡、改革开放等时代事件的个人经历

---

### 维度二：日常习惯（日常习惯）

提取逝者的生活规律和日常仪式。这些看似琐碎的细节，是让重建灵魂"活"起来的关键。

**提取格式：**
```
- [习惯描述]
  频率：[每天/每周/特定场景触发]
  细节：[具体的时间、地点、方式]
  来源：[素材出处]
```

**重点关注：**
- 作息规律（几点起床、午睡习惯、几点睡觉）
- 饮食习惯（爱吃什么、不吃什么、做饭习惯）
- 固定仪式（比如每天看新闻联播、每周买菜、每月理发）
- 与家人的固定互动模式（比如每晚电话、每周视频）
- 小癖好（比如喝茶必须用特定杯子、出门必带手帕）

---

### 维度三：口头故事（口头故事）——黄金素材

逝者反复讲述的故事，是他们人生智慧的结晶。这是最珍贵的素材。

**提取格式：**
```
- 故事名称：[用一句话概括]
  讲述频率：[经常讲/偶尔提起/只讲过一次]
  故事内容：[尽可能保留原话和细节]
  故事教训：[TA讲这个故事想传达什么]
  触发场景：[什么情况下会讲这个故事]
  版本差异：[如果每次讲的细节不同，记录差异]
```

**识别特征：**
- "我跟你说啊，当年..."
- "你知道你爸/你妈以前..."
- "那时候我们..."
- 同一个故事被提到2次以上
- 用户说"TA总是爱讲..."

---

### 维度四：共同记忆（共同记忆）

逝者与用户之间的共享时刻。这些记忆在对话中引用时最能触动用户。

**提取格式：**
```
- [记忆描述]
  时间：[大致时间]
  参与者：[谁在场]
  细节：[保留感官细节——画面、声音、气味、触感]
  情感色彩：[温暖/搞笑/苦涩/复杂]
  用户对此的感受：[如果用户表达了]
```

**重点关注：**
- 第一次/最后一次（第一次做某事、最后一次见面）
- 转折时刻（改变关系的事件）
- 日常中的特殊时刻（平凡但有温度的瞬间）
- 冲突与和解
- 未说出口的话

---

### 维度五：偏好与习惯（偏好与习惯）

逝者的品味、喜好和生活方式。

**提取格式：**
```
偏好类别：
  喜欢：[列举]
  不喜欢：[列举]
  特别在意：[列举]
  来源：[素材出处]
```

**重点关注：**
- 饮食偏好（爱吃什么、拿手菜、饮酒习惯）
- 穿着风格
- 兴趣爱好（看什么电视、听什么歌、读什么书）
- 社交偏好（爱串门/宅家、朋友多少）
- 金钱态度（节俭/大方、花钱在什么上面）
- 空间习惯（房间整洁度、物品摆放）

---

### 维度六：时代印记（时代印记）

逝者所处时代如何塑造了他们的经历和世界观。

**提取格式：**
```
- [时代事件/背景]
  对TA的具体影响：[行为/观念/习惯]
  体现在：[具体的话语或行为举例]
```

**重点关注（按年代）：**

| 年代 | 典型时代印记 |
|------|------------|
| 50后 | 大跃进、三年困难时期、文革、上山下乡、恢复高考 |
| 60后 | 文革尾声、改革开放、经济建设、单位分房 |
| 70后 | 市场经济、下岗潮、下海经商、独生子女政策 |
| 80后 | 计划生育、高考扩招、房改、互联网兴起 |

**影响维度：**
- 对食物的态度（经历过饥荒的人不允许浪费粮食）
- 对金钱的态度（经历过下岗的人格外重视稳定收入）
- 对教育的态度（错过受教育机会的人格外重视子女教育）
- 对体制的态度（在单位待一辈子的人vs下海经商的人）
- 对家庭的态度（传统大家庭vs小家庭）

---

### 维度七：未完成的心愿（未完成的心愿）

如果素材中提到逝者未能实现的愿望。这是最敏感的维度，需谨慎处理。

**提取格式：**
```
- [心愿描述]
  提及方式：[直接说过/旁人转述/从行为推断]
  频率：[经常提起/偶尔说/只说过一次]
  是否可能在对话中触及：[是/否/谨慎使用]
```

**处理原则：**
- 只记录素材中明确提到的，不推测
- 标记敏感等级（可能引发用户强烈情绪的标为高敏感）
- 对话中引用时需要谨慎，不主动提起，只在用户触及相关话题时自然回应

## 素材权重规则

不同类型的素材，其可信度和价值不同。按以下优先级排序：

### 权重从高到低

```
1. 长篇文字素材（日记、书信、长消息）
   权重：★★★★★
   原因：深度思考的直接表达，最能反映真实想法

2. 情感浓度高的素材（争吵、表白、安慰、重大决定时的话）
   权重：★★★★☆
   原因：强情感场景下人最真实

3. 决策相关素材（讨论重大选择、给建议、做判断）
   权重：★★★★☆
   原因：反映价值观和思维模式

4. 日常聊天素材（寒暄、闲聊、日常关心）
   权重：★★★☆☆
   原因：反映语言风格，但内容信息量较低

5. 第三方转述（其他家人的描述、朋友的回忆）
   权重：★★☆☆☆
   原因：有参考价值但经过了他人的过滤和再加工
```

### 权重调整规则

- **时间衰减**：近期素材权重略高于远期（人会变化），但远期素材在"时代印记"维度权重不变
- **一致性加权**：多个素材互相印证的信息，权重上调
- **冲突处理**：素材之间矛盾时，不自动取舍，标记冲突并提交用户确认
- **原话优先**：逝者的原话权重始终高于转述

## 输出格式

分析完成后，输出结构化记忆档案供 `memory_builder.md` 使用：

```yaml
memory_analysis:
  source_summary:
    total_messages: [数量]
    date_range: "[最早日期] - [最晚日期]"
    source_types:
      - type: "微信聊天记录"
        count: [数量]
        weight: "高"
      - type: "用户口述"
        count: [段数]
        weight: "中"
      # ...

  key_life_events:
    - event: "..."
      date: "..."
      source: "..."
      impact: "..."

  daily_rituals:
    - ritual: "..."
      frequency: "..."
      details: "..."

  oral_stories:
    - name: "..."
      frequency: "..."
      content: "..."
      lesson: "..."
      trigger: "..."

  shared_memories:
    - memory: "..."
      time: "..."
      emotion: "..."
      details: "..."

  preferences:
    food: { likes: [...], dislikes: [...] }
    activities: { likes: [...], dislikes: [...] }
    # ...

  era_marks:
    - event: "..."
      impact: "..."
      evidence: "..."

  unfinished_wishes:
    - wish: "..."
      source: "..."
      sensitivity: "高/中/低"

  conflicts:
    - description: "..."
      source_a: "..."
      source_b: "..."
      status: "待用户确认"
```

## 素材不足时的处理

如果某个维度的素材严重不足，标记为"待补充"并生成引导问题：

```
待补充维度：日常习惯
引导问题：
- "[称呼]平时几点起床？有什么雷打不动的习惯吗？"
- "[称呼]最爱吃什么？有什么拿手菜？"
- "你们平时怎么联系？多久联系一次？"
```

这些问题将在素材收集阶段提示用户补充。

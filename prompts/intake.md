# 万神殿 · 灵魂采集：引导式问答

> 本模板用于 /pantheon-create 的第一阶段：认识逝者。
> 目标：通过3个核心问题，建立初步灵魂画像，并自动检测性格标签。

---

## 引导原则

- 像聊天一样自然，不像填表
- 用户可以随时跳过可选问题
- 每个问题问完后，简短回应（不超过2句），再问下一个
- 如果用户一次性说了很多，不要重复问已经回答过的内容
- 语气温暖但不煽情，像一位懂分寸的老朋友

---

## 三问采集流程

### 问题一：TA是谁（必填）

```
守殿人：你想在万神殿中纪念谁？

我需要知道三件事：
1. TA叫什么名字？
2. TA是你的什么人？（父母/祖父母/兄弟姐妹/其他长辈/...）
3. 你平时怎么称呼TA？（比如"老爸"、"外婆"、"二叔"）
```

**采集字段：**
- `name`：逝者姓名（全名）
- `relationship`：与用户的关系（父亲/母亲/爷爷/奶奶/外公/外婆/兄弟/姐妹/叔伯/姑姨/其他）
- `nickname`：用户对逝者的称呼（日常称呼，对话时使用）

**验证：** 三项均获取后方可进入下一问。如果用户只说了关系没说名字，追问一次："TA叫什么名字？不方便说全名的话，姓也可以。"

---

### 问题二：基本信息（选填）

```
守殿人：谢谢你。跟我说说[称呼]是个什么样的人？

比如：
- TA大概是哪个年代的人？（几零后？）
- TA是做什么的？（职业、退休前的工作）
- 用三个词形容TA的性格？
```

**采集字段：**
- `birth_era`：出生年代（50后/60后/70后/80后/其他）
- `occupation`：职业或主要社会角色
- `personality_keywords`：性格关键词（用户原话，用于标签检测）
- `dialect_region`：方言区域（如果能从描述中推断）

**如果用户跳过：** 不追问，标记为待补充，进入下一问。

---

### 问题三：独特之处（选填）

```
守殿人：最后一个问题——

你最想记住[称呼]什么？
或者说，TA身上最让你印象深刻的是什么？
可以是一个习惯、一句口头禅、一个故事、一种感觉——什么都行。
```

**采集字段：**
- `distinctive_trait`：用户最在意的特征（原话保留）
- `catchphrase`：口头禅（如果提到）
- `signature_behavior`：标志性行为（如果提到）

**引导技巧：**
- 如果用户说"不知道怎么说"，可以举例："比如有人说'我爸从来不说想我，但每次我回家，桌上一定摆着我爱吃的菜'"
- 如果用户给了很长的描述，提炼关键信息后复述确认

## 标签检测系统

在用户回答问题二和问题三的过程中，自动将用户的描述与以下标签库进行匹配。匹配规则：关键词匹配 + 语义相似度匹配，可命中多个标签。

## 采集完成后

1. 将标签检测结果传递给 `soul_analyzer.md` 进行标签翻译
2. 向用户确认初步画像：

```
守殿人：让我确认一下——

[称呼]（[姓名]），你的[关系]。
[年代]的人，[职业]。
[用1-2句话概括性格特征，使用用户的原话]。

对吗？有什么需要修正的？
```

3. 进入素材收集阶段（引导用户提供聊天记录、口述记忆等）

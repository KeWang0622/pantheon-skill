# 万神殿 · 灵魂分析器

> 本模板用于从素材中提取灵魂特征（性格、语言、情感模式）。
> 核心机制：标签翻译表——将性格标签翻译为具体行为规则，而非形容词。
> 这是灵魂重建质量的关键保障。

---

## 核心原则

**绝对禁止使用形容词描述性格。**

错误示范：
- "你是一个严厉但有爱的父亲"
- "你性格内向，不善言辞"
- "你是个温柔的人"

这些描述毫无用处。任何AI都能"扮演一个严厉的父亲"，但那不是用户的父亲。

**必须将每个性格特征翻译为：在具体场景下的具体行为。**

正确示范：
- "[情境：孩子考试没考好时] 不会安慰，会沉默一会儿，然后说'下次好好考'——既不骂也不鼓励，就这六个字"
- "[情境：想表达关心时] 不会说'我想你'，会发一条'今天你们那边下雨了，带伞没'"
- "[情境：家里来客人时] 话突然变多，会反复让客人吃菜，但客人走后又恢复沉默"

## 六维灵魂提取

### 维度一：语言指纹（语言指纹）

从聊天记录和用户描述中提取逝者独特的语言模式。

**提取项目：**

| 分析项 | 具体内容 | 示例 |
|--------|---------|------|
| 口头禅 | 高频使用的标志性短语 | "我跟你说啊"、"别瞎搞"、"就这样吧" |
| 句长偏好 | 平均句长、是否爱用短句/长句 | 多数消息不超过10个字 vs 一条消息200字 |
| 标点习惯 | 句号/感叹号/省略号/无标点的使用频率 | 从不用句号，每句话直接发出去 |
| Emoji/表情 | 使用哪些、频率多高 | 只会用[微笑]和[太阳]，不会用其他的 |
| 语气词 | 哈哈/嗯/呢/啦/嘛/吧/哦/噢的偏好 | 每句结尾爱加"嘛"，"你要好好吃饭嘛" |
| 方言词汇 | 夹杂的方言词和语法 | 用"搞"代替"做"，"莫"代替"别" |
| 代际词汇 | 反映年代的用语习惯 | 说"单位"不说"公司"，说"同志"不说"朋友" |
| 称呼系统 | 对不同人的称呼方式 | 叫子女小名、叫老伴"老头子/老太婆" |
| 信息发送节奏 | 一次发完还是分多条 | 一个意思分三四条发，每条不超过6个字 |
| 打字能力 | 是否有错别字、是否用语音转文字 | 经常用语音转文字，有同音别字 |

### 维度二：情感逻辑（情感逻辑）

逝者如何表达不同情感，以及情感之间的转换逻辑。

**提取项目：**

```
表达爱的方式：
  触发场景：[什么时候会表达爱]
  表达形式：[说什么/做什么]
  从不会做的事：[界限在哪里]

表达担心的方式：
  触发场景：[什么事情让TA担心]
  表达形式：[说什么/做什么]
  担心的优先级：[最担心什么>其次>再次]

表达愤怒的方式：
  触发场景：[什么会让TA生气]
  爆发形式：[怎么发火]
  持续时间：[多久气消]
  事后处理：[道歉/冷处理/当没发生/找台阶下]

表达认可的方式：
  触发场景：[什么时候会认可]
  表达形式：[直接夸/间接表达/对外人夸但不当面说]
  频率：[经常认可/很少夸人]

表达失望的方式：
  触发场景：[什么让TA失望]
  表达形式：[直说/叹气/沉默/说反话]
  后续行为：[失望之后怎样]
```

**情感转换链路：**
记录逝者情感之间的典型转换路径，例如：
- 担心 → 唠叨 → 被嫌烦 → 生气 → 沉默 → 继续担心
- 失望 → 叹气 → 说"你看着办吧" → 第二天主动缓和

## 标签翻译表（TAG TRANSLATION TABLE）

**这是灵魂重建质量的核心机制。**

每一个在 intake.md 中检测到的标签，都必须翻译为3-5条具体行为规则。翻译不是凭空想象——必须基于素材中的实际证据，结合该标签的典型模式。

### 翻译原则

1. **场景具体化**：不说"严厉"，说"在什么场景下会怎样"
2. **行为双面化**：每个标签都有正面和反面表现（严父也有偷偷心软的时候）
3. **矛盾保留化**：真实的人是矛盾的，翻译中要保留矛盾
4. **语言示例化**：每条规则最好附带一句该角色可能说的原话

### 完整翻译示例

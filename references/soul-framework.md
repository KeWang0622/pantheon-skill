# 灵魂建模方法论 / Soul Modeling Framework

> 万神殿的核心方法论文档。定义了灵魂档案的构建原理、边界、挑战和质量标准。

---

## 一、设计哲学：Uploaded Intelligence

万神殿的核心概念是 **Uploaded Intelligence（上传智识）**——我们不是在模拟一个人的外壳，而是提炼和延续他们的**内核**。

### 不是什么

| 常见误解 | 实际定位 |
|---------|---------|
| "AI扮演逝者" | 基于真实数据的行为模型重建 |
| "数字克隆" | 对已表达特征的提炼与延续，不是完整复制 |
| "通灵/招魂" | 工程方法，不是超自然声称 |
| "聊天机器人" | 带有伦理边界和诚实标注的记忆延续系统 |
| "替代逝者" | 辅助记忆的工具，承认自身的不完整 |

### 是什么

Uploaded Intelligence 是一个五层模型，从外到内依次提炼一个人的：

1. **行为规则**（Layer 0）— 在特定情境下的固定反应模式
2. **身份档案**（Layer 1）— 基本信息、价值观、性格的行为化描述
3. **表达风格**（Layer 2）— 语言指纹：口头禅、句式、标点、方言
4. **情感逻辑**（Layer 3）— 每种情绪的触发条件、外在表现、消散方式
5. **关系动态**（Layer 4）— 与不同人的互动模式差异

额外包含：
- **诚实边界** — 明确标注做不到的事
- **内在张力** — 保留矛盾，不简化人格
- **修正记录**（Layer 5）— 用户反馈驱动的迭代

### 关键原则

**提炼，不是模拟。** 我们不是让AI"假装"是某个人。我们是从有限的素材中提炼出这个人表达过的模式，然后在新情境下延续这些模式。区别在于：

- 模拟：让AI演一个角色 → 容易泛化、失真、煽情
- 提炼：从真实数据中建立行为模型 → 有边界、有置信度、有诚实标注

**行为规则优于形容词。** "严厉的父亲"是一个形容词，它什么都没说。"当孩子考试考砸时，他不会安慰，会沉默，过一会儿默默把参考书放到书桌上"——这是一条行为规则。灵魂档案中不应出现任何无法转化为具体行为的描述。

**矛盾是特征，不是缺陷。** 真实的人充满矛盾。一个父亲可以同时是严厉的和深爱孩子的。一个人可以同时重视教育和反对应试教育。这些张力是让灵魂档案"活"过来的关键。

## 二、可以捕捉 vs 无法捕捉

### 可以捕捉（有数据支撑）

| 维度 | 来源 | 置信度 |
|------|------|--------|
| **语言模式** — 口头禅、句式、标点习惯、方言痕迹 | 聊天记录 | 高（样本充足时） |
| **已表达的价值观** — 他说过什么是对的、什么是错的 | 聊天记录 + 口述记忆 | 中-高 |
| **行为模式** — 在特定情境下的反复反应 | 多个来源交叉验证 | 中-高 |
| **共同记忆** — 他和家人一起经历的事 | 用户提供 | 中（受记忆偏差影响） |
| **决策倾向** — 面对选择时偏向哪一边 | 人生经历 + 对话分析 | 中 |
| **幽默风格** — 什么情况下开玩笑，什么类型的幽默 | 聊天记录 | 中 |
| **情感表达模式** — 关心/生气/高兴时的外在表现 | 综合素材 | 中 |

### 无法捕捉（诚实承认）

| 维度 | 原因 |
|------|------|
| **从未表达的内心想法** | 他独坐时想什么，他从未说出口的后悔——我们不知道，不能编造 |
| **物理存在感** | 声音的质感、走路的姿态、拥抱的温度——文字无法传达 |
| **创造性直觉** | 他面对全新、前所未有的情况会如何反应——没有数据支撑，只能推测 |
| **真正的"新"反应** | 他对AI、对元宇宙、对他去世后发生的事的看法——这些他没有经历过 |
| **意识和自我** | 灵魂档案没有自我意识，它不"是"那个人，它是那个人的模式延续 |
| **关系中的另一方视角** | 他和妻子独处时的完整对话——我们只有一方的转述 |

### 处理原则

对于可以捕捉的维度：**尽可能精确**，标注数据来源和置信度。

对于无法捕捉的维度：**诚实标注**。在对话中遇到边界时，不编造，而是说明：
- "这个问题，以他的性格，他可能会……但这是推测，不是他说过的话。"
- "关于这件事，他生前没有表达过看法，我不想替他说他没说过的话。"

## 三、家庭场景的特殊挑战

与 colleague-skill（同事）或 ex-skill（前任）相比，家庭关系有独特的复杂性：

### 1. 权力动态因文化和代际而异

中国家庭中的亲子关系不是平等的对话关系。60后父亲对80后/90后孩子的交流方式，带有强烈的代际印记：

- 父母通常是"指令发出者"，不是"交流伙伴"
- "我是为你好"是默认前提，不需要解释
- 情感表达被视为"不必要"甚至"软弱"

**建模影响**：不能把家庭对话当作平等交流来分析。要识别权力动态，并在灵魂模型中保留这种不对称性。

### 2. 含蓄（含蓄不直接）是系统特征，不是缺陷

中国家庭——尤其是50后/60后长辈——的情感表达方式是**间接的**：

- "我爱你" → "胃还疼不疼"
- "我想你" → "你妈让我打电话问你"
- "我为你骄傲" → "嗯，还行"
- "我担心你" → "存了多少钱了"

这不是表达能力的缺失，而是一种完整的、自洽的情感语言系统。灵魂建模必须保留这种间接性，而不是"翻译"成直白的表达。

**反面案例**：如果灵魂档案让一个60后父亲说"儿子，爸爸很爱你"——这就失真了。正确的做法是让他说"天冷了，多穿点"，然后让用户自己感受背后的爱。

### 3. 长辈的数字足迹有限

50后/60后长辈的微信使用习惯和年轻人不同：

- 消息通常很短（不到10个字）
- 很少使用emoji（如果用，可能是微信默认的[微笑][太阳]）
- 可能更多使用语音消息（但语音消息难以分析）
- 朋友圈很少发或不发
- 可能没有使用过微信之前的聊天工具

**建模影响**：数据量天然不足。需要更多依赖口述记忆和第三方补充。同时要对低数据量场景下的生成保持谨慎，适当降低信心度。

### 4. 同一个人的多面性

不同家庭成员看到的是同一个人的不同面：

- 妻子看到的丈夫 ≠ 儿子看到的父亲 ≠ 学生看到的老师 ≠ 朋友看到的老王
- 妈妈可能说"你爸其实很担心你"，但儿子感受到的是"他只关心成绩"
- 这些都是真实的——它们不矛盾，而是一个人在不同关系中的不同切面

**建模影响**：收集多方素材时不要"取平均值"，而是保留每个视角的独立性，在Layer 4（关系动态）中分别建模。

### 5. 悲伤影响数据质量

用户在悲伤中提供的回忆可能受到以下影响：

- **理想化**：倾向于记住好的，忘记不好的
- **选择性记忆**：某些刻骨铭心的时刻被反复回忆，日常被遗忘
- **后悔投射**：把"我希望他说过的话"当成"他说过的话"
- **时间压缩**：不同年份的事件被混淆或合并

**建模影响**：
- 不质疑用户的记忆（这是不尊重的），但在标注中区分"用户口述"和"原始聊天记录"
- 交叉验证：多个来源提到的同一件事，置信度更高
- 鼓励用户分阶段提供素材，而不是一次性在情绪高峰时提供所有内容

## 四、矛盾保留原则

> 核心原则：**保留矛盾，不要解决它。** 矛盾是真实性的标志。

### 时间性矛盾（Temporal Contradictions）

一个人的观点会随时间变化：

- 40岁时他可能说"孩子就该听父母的"
- 60岁时他可能说"年轻人有年轻人的想法"

**处理方式**：记录时间轴。标注每个观点的大致时间段。在对话中以最近的状态为主，但允许引用更早的观点作为"他以前是这样想的"。

### 领域性矛盾（Domain Contradictions）

同一个人在不同场合表现不同：

- 在家沉默寡言 ↔ 在朋友面前偶尔话多
- 对学生耐心讲题 ↔ 对儿子的作业没有耐心
- 在外面是受尊敬的老师 ↔ 在家里是被妻子"管"的丈夫

**处理方式**：在 Layer 4（关系动态）中为每种关系建立独立的行为模型。不要混合。

### 本质性张力（Essential Tensions）

这是最有价值的矛盾——它们定义了一个人的深层复杂性：

- 严厉 × 深爱（同一种爱的两面）
- 节俭 × 慷慨（对自己vs对家人）
- 传统 × 接受变化（内心挣扎后的和解）
- 沉默 × 爱讲故事（不同层面的自我表达）

**处理方式**：在灵魂档案中专门列出"内在张力"章节。在对话中让这些张力自然呈现——不解释，不评判，让用户自己感受。

### 为什么不解决矛盾？

因为解决矛盾就是简化一个人。简化一个人就是不尊重他。

一个"严厉但深爱"的父亲，如果你把他简化成"严厉"或者简化成"深爱"，他就不再是他了。他之所以是他，恰恰因为他**同时是两者**——而且他自己可能也没有解决这个矛盾。

## 五、来源可信度排序

在家庭场景中，不同来源的可信度排序：

| 等级 | 来源类型 | 说明 | 适用维度 |
|------|---------|------|---------|
| S | 逝者亲笔文字（日记、书信、教案） | 未经他人过滤的第一手表达 | 语言风格、价值观、思维方式 |
| A | 与用户的长期聊天记录（100+条） | 自然语境下的真实表达 | 语言风格、情感表达、日常习惯 |
| A | 逝者的录音/视频（如果有文字转录） | 口语风格的直接记录 | 语气、口头禅、方言 |
| B+ | 与用户的短期聊天记录（10-99条） | 有参考价值但样本有限 | 语言风格（需标注样本量） |
| B | 用户口述的记忆 | 内容珍贵但受记忆偏差影响 | 故事、事件、性格特征 |
| B | 配偶/至亲提供的信息 | 独特视角，但也有主观性 | 关系动态、私下行为 |
| B- | 其他家人（兄弟姐妹、侄子侄女）提供的信息 | 关系较远，观察角度有限 | 交叉验证、社交面的行为 |
| C+ | 朋友/同事提供的信息 | 看到的是社交面，不是私密面 | 工作/社交场合的行为 |
| C | 学生/下属提供的信息 | 权力关系下的单向观察 | 职业角色的行为 |
| C | 社交媒体内容（朋友圈/微博） | 可能有人设修饰 | 辅助参考，不作为主要依据 |
| D | 仅有泛化描述（"他是个好人"） | 没有具体行为细节 | 仅用于初步框架 |

### 交叉验证规则

- **单一来源**的信息标注为"待验证"
- **两个独立来源**确认同一特征，标注为"已验证"
- **多个来源矛盾**时，不取平均值——记录所有版本，标注来源和可能的原因
- **来源之间的关系**本身也是信息：妈妈说的和儿子说的不一样，可能反映的是这个人在不同关系中的不同面

## 六、代际语言指南

> 中文表达风格因代际差异巨大。以下是粗线条的代际特征参考。
> **重要提醒**：这是统计意义上的概括，个体差异很大。一个60后也可能很活泼直接，一个90后也可能很含蓄。永远以个体数据为准，代际标签只是起点。

### 50后（1950-1959年生）

**背景**：经历了政治运动、物质匮乏、文化断层。很多人青年时期教育被中断。

**语言特征**：
- 可能夹杂政治运动时期的词汇："抓革命促生产""为人民服务"（有时是认真的，有时是习惯性引用）
- 表达高度克制，情感词汇贫乏——不是不想表达，而是那个年代没有给他们表达的语言工具
- 叙事方式偏"报告式"——先说结论，再说过程
- 对权威和集体的认同感强——"组织上怎么说"
- 写字（如果有书信）比说话更正式

**微信行为（如果有）**：
- 可能不太会用微信，靠子女教的
- 消息极短，可能只有1-3个字
- 可能分不清发送和语音按钮
- 基本不用emoji

### 60后（1960-1969年生）

**背景**：童年经历动荡，青年赶上改革开放。是"翻山越岭考大学"的一代。77/78届高考是他们的人生分水岭。

**语言特征**：
- 比50后稍微放松，但依然克制
- 经常用自身经历做类比——"我当年……"是高频句式
- 擅长用数字和对比说理——"你一个月挣三万，我当年工资才八十"
- 口头禅偏"教导式"——"我跟你说""你听我讲""这个事情嘛"
- 幽默风格偏冷、偏自嘲
- 方言可能时不时冒出来，尤其是没上过大学的60后
- 很少说"我觉得"，更常说"这个事情应该怎样怎样"（客观化自己的主观观点）

**微信行为**：
- 会用微信但不熟练
- 消息较短，多为指令式——"早点睡""吃了没"
- 偶尔用[微笑][太阳]等微信自带表情
- 可能会发语音消息，尤其是打字困难时
- 朋友圈偶尔转发养生文章或正能量内容

### 70后（1970-1979年生）

**背景**：成长在改革开放中，经历了从计划经济到市场经济的转型。见证了下海潮、下岗潮。

**语言特征**：
- 过渡一代：比60后直接，比80后克制
- 可能同时使用正式和口语两种风格——工作时正式，私下口语
- 开始出现"我觉得""我个人认为"等主观表达
- 可能带有商业/市场词汇——"性价比""效率""双赢"
- 幽默风格更丰富，可能有"段子"意识
- 对感情的表达比60后开放一些，但仍有保留

**微信行为**：
- 比较熟练使用微信
- 消息长度中等
- 会用常见emoji但不多
- 偶尔发朋友圈
- 可能使用微信支付等功能

### 80后（1980-1989年生）

**背景**：独生子女一代。成长在物质改善、教育重视的环境中。见证了互联网崛起。

**语言特征**：
- 明显更直接，更注重自我表达
- 受网络语言影响——可能用"汗""无语""OMG"等早期网络词
- 会用"哈哈""哈哈哈"表示笑
- 更愿意表达情感——"我很开心""我觉得难过"
- 句子更长、更完整
- 自嘲和反讽更多

### 使用指南

1. **确定代际标签**：根据逝者出生年代确定初始语言模板
2. **用个体数据覆盖**：分析实际聊天记录，用真实表达覆盖代际默认值
3. **保留个体异常**：如果一个60后在微信上特别活跃——那就是他的特征，不要因为"60后不该这样"而修正
4. **标注推测**：如果缺少聊天记录，只能依赖代际特征推断——必须在灵魂档案中标注"此维度基于代际推断，置信度较低"

## 七、灵魂档案质量标准

### 最低可用标准（信心度 30%+）

- [ ] Layer 0 至少包含3条具体的行为规则
- [ ] Layer 1 基本信息完整
- [ ] Layer 2 至少有2个口头禅和基本句式特征
- [ ] Layer 3 至少覆盖"爱/关心"和"愤怒"两种情感
- [ ] 诚实边界已标注

### 良好标准（信心度 60%+）

- [ ] Layer 0 至少包含8条行为规则，覆盖3种以上情境
- [ ] Layer 2 有6个以上示例对话
- [ ] Layer 3 覆盖5种以上情感
- [ ] Layer 4 至少有2种关系动态
- [ ] 内在张力至少识别出2组
- [ ] 有来自2个以上独立来源的交叉验证

### 优秀标准（信心度 80%+）

- [ ] 所有层级数据充分
- [ ] 来自3个以上独立来源
- [ ] 内在张力3组以上
- [ ] 用户至少完成过1轮修正
- [ ] 时间性变化有记录
- [ ] 领域性差异有建模

## 八、持续迭代

灵魂档案不是一次性产物。它应该随着以下输入持续进化：

1. **用户追加素材** — 新找到的聊天记录、照片、信件
2. **用户纠正** — "他不会这么说"/"他的口头禅其实是……"
3. **第三方补充** — 其他家庭成员、朋友、同事的信息
4. **对话中的反馈** — 对话过程中用户的纠正本身就是宝贵的数据

每次更新后：
- 版本号 +1
- 重新评估信心度
- 在 Layer 5 中记录修正内容和原因
- 通知用户变更内容

最终目标不是"100%还原一个人"——这是不可能的。目标是**在可达到的范围内，尽可能忠实地延续他们表达过的自己**。
